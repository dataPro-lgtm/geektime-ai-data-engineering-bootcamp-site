# Geektime AI Data Engineering Bootcamp Site

This repository is the public delivery target for the course site.

What it contains:
- the generated static site used by GitHub Pages
- downloadable lesson handouts in PDF and Word format

What it does not contain:
- source authoring files
- planning, research, or internal course production assets

Publishing model:
- source content is maintained in a separate private repository
- the private repository builds the Quarto site and pushes the rendered output here
- GitHub Pages serves the `gh-pages` branch of this repository

Public site:
- <https://datapro-lgtm.github.io/geektime-ai-data-engineering-bootcamp-site/>

This repository should stay minimal. Do not edit site content here by hand unless fixing a publishing emergency.
